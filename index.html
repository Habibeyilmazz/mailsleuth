Is this email what it says it is?

Give mailsleuth the full message and it explains every warning sign it finds: forged senders, failed SPF, DKIM and DMARC checks, look-alike domains, disguised links and dangerous attachments.

Gmail: ⋮ › Show original. Outlook: ⋯ › View › View message source. Headers alone also work; body text alone gets only the link and wording checks.

  • Sender From, Reply-To and Return-Path compared; brand names in display names; look-alike and punycode domains.
  • Authentication SPF, DKIM, DMARC and ARC results translated into plain English.
  • Delivery path Every server hop on a timeline, with the delay between them.
  • Links Safe Links and other wrappers decoded; text that lies about the destination; shorteners, IP addresses, data: links.
  • Attachments SHA-256 hashes; macros, double extensions, HTML, ISO and LNK files found by their structure.

mailsleuth makes no network requests: this page is locked down so it cannot. Lookup buttons open VirusTotal, URLhaus or MalwareBazaar in a new tab with only that link or hash. Source on GitHub (MIT).
